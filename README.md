# Projeto final de curso

## Resumo:
O projeto é um sistema de consciliação entre empresas de atividades fisicas e usuarios que buscam profissionais nas respectivas areas, exemplo: IFood.

## Autores:
Bruna Hazama, Derik Kauã e Kayke Bueno.

## Objetivo do programa:
Auxiliar os usuários a encontrar o esporte que mais combine com ele para que não seja um peso praticá-lo e sim um hobby.

## Principais Funcionalidades:
- analisar a sistemática de de testes de aptidão física e mental;
- Identificar os principais problemas existentes relacionados ao assunto;
- propor soluções aos problemas observados;
- identificar os requisitos funcionais e não funcionais do sistema;
- documentar o sistema de acordo com as seguintes funcionalidades:
  - gerenciar usuários (empresa e atleta);
  - gerenciar questionários;
  - gerenciar tipos de questionários;
  - gerenciar esportes;
  - gerenciar treinos;
  - emitir relatórios gerenciais;
- implementar o sistema proposto;
- realizar testes para analisar o funcionamento do sistema.

## Tecnologias Utilizadas:
php, html, css, mysql e js.

## Passo a passo de como rodar o projeto:
baixar e utilizar o xamp.
